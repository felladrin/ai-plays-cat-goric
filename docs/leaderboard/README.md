# Leaderboard results

One folder per benchmark version (`v1`, `v2`, ...), and in it one `benchmark.json` per model, as `npm run benchmark` wrote it, named after the model. `driver/leaderboard.cjs` renders them into the tables in [../../readme.md](../../readme.md#leaderboard) and [../benchmark.md](../benchmark.md). The rules for a result to count are in [../benchmark.md](../benchmark.md#versions).
